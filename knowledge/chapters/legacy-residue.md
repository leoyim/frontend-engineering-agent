## 五、`原书第 N 章` 这类引用怎么读

**D0 / D2 / D3 各章的「本章定位」与尾注里，仍会出现「原书第 N 章 §x.y」这样的写法。** 这是**来源标注**，不是指路链接。

| 情形 | 含义 |
|---|---|
| 「骨架来自**原书第 1 章 §1.1**」 | 说明该节的血缘，便于追溯改写幅度 |
| 「与原书第 2 章 §2.4 的结论一致」 | 说明结论曾被课程确认过（**不是**引用原文） |
| 「原书第 7 章 §7.3 有一套动手项目」 | **原文件已删除**（2026-10-17）→ 内容现在在 **`README.md` 的「怎么读」**·五个动手项目 |

**为什么不做全局替换**：`MIGRATION_PLAN.md` 原计划把这类引用全部换掉，但**换掉会抹掉溯源信息** —— 读者将无法知道某段内容是从哪一段改写来的、改了多少。**保留 + 在本文档建立映射（§一）** 是更诚实的选择：想知道原文长什么样，查 git 历史；想只知道"它原来在哪"，查 §一。

**所以**：见到「原书第 1–7 章」的引用，**一律当历史标注读** —— 原书章节文件已全部删除（2026-10-17），想知道原文长什么样请查 git 历史；想知道"它原来在哪"，查本文档 §一。
